# Requirements Register

Full register of requirements derived from *Silabus Operasional Pembinaan OSN Informatika 2026*
(`docs/silabus/`). See `README.md` in this directory for the ID scheme, status vocabulary, and
verification methods. See `traceability.md` for the section↔requirement↔issue matrices that
prove this register is exhaustive.

77 requirements: 26 `FR`, 11 `TR`, 12 `OR`, 16 `ER`, 12 `GR`.
