# 3. Struktur Kurikulum: Core, Support, dan Extension

| Kategori | Isi | Aturan |
| --- | --- | --- |
| CORE | Seluruh rumpun resmi OSN 2026; complexity/constraint analysis; C++ implementation discipline; contest strategy. | Wajib dikuasai sebelum memperluas materi. |
| SUPPORT | Prefix sum, difference array, two pointers, sliding window, set/map, debugging workflow, stress testing, proof sketch. | Digunakan sebagai alat pemecahan masalah dan implementation engineering. |
| EXTENSION | Topological sort, SCC, balanced BST concept, interval DP, bitmask DP, string algorithms, convex hull algorithm, advanced graph/DP. | Masuk setelah core stabil; cek silabus terbaru dan kebutuhan siswa. |
| DE-PRIORITIZED | Implementasi AVL spesifik, linear algebra sebagai blok besar, hafalan Matrix Chain Multiplication, KMP/Z sebagai materi wajib. | Tidak dialokasikan waktu core kecuali ada tujuan kompetisi lanjutan yang jelas. |

> **Aturan dependency** - Tidak memperkenalkan struktur data/algoritma lanjutan hanya karena populer. Materi baru diberikan bila prasyarat konsep, complexity, dan kemampuan implementasinya sudah cukup stabil.
