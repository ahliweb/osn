# 14. Checklist Kesiapan dan Aturan Operasional

## 14.1 Checklist sebelum memulai cohort

- Verifikasi silabus resmi OSN dan halaman OSN-K/OSN-P terbaru.
- Tetapkan kalender 28 minggu terhadap jadwal sekolah dan seleksi.
- Lakukan diagnostic C++, logika, matematika, complexity, dan problem solving.
- Kelompokkan siswa berdasarkan gap, bukan hanya kelas/usia.
- Siapkan problem bank terkurasi untuk semua minggu dan minimal satu alternatif per topik.
- Siapkan judge/account, template C++ minimal, dashboard mentor, dan error taxonomy.
- Tetapkan rubrik A/B/C/D, hint policy, upsolve policy, dan checkpoint.
- Tetapkan perlindungan data, akses mentor, retensi, backup, dan incident contact.

## 14.2 Aturan operasional final

1. Core OSN harus lebih dahulu daripada extension.
2. C++ fundamentals, computational thinking, complexity, dan constraint analysis diberikan sejak awal.
3. Latihan dan tracing dimulai Minggu 1; Minggu 25-28 adalah integrasi intensif.
4. DP diajarkan melalui state-transition-base case-complexity.
5. Graph/data structure selalu dimulai dari operasi/constraint dan model masalah.
6. Setiap contest wajib postmortem dan upsolve.
7. Jumlah soal bukan satu-satunya KPI; mastery dan transfer lebih penting.
8. Setiap versi silabus harus memiliki tanggal, changelog, dan syllabus check.

> **Pointer cepat untuk mentor** - Problem Solving -> C++ -> Complexity -> Math/Logic -> Complete Search -> Greedy -> DP -> Graph/Tree -> Data Structures -> Contest Engineering. Extension hanya setelah core stabil.
