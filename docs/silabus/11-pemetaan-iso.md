# 11. Pemetaan Standar ISO/IEC

Standar berikut relevan untuk tata kelola organisasi dan platform pembinaan, bukan materi ujian OSN.

| Standar | Relevansi | Penerapan |
| --- | --- | --- |
| ISO 21001:2025 [[R22]](99-referensi.md#r22) | Educational organization management | Learner-centered quality, feedback, inclusion, continuous improvement. |
| ISO/IEC 27001:2022 [[R23]](99-referensi.md#r23) | ISMS | Risk-based security untuk LMS, judge, akun, database, cloud. |
| ISO/IEC 27002:2022 [[R24]](99-referensi.md#r24) | Security controls | Access control, logging, asset/configuration management, incidents. |
| ISO/IEC 27005:2022 [[R25]](99-referensi.md#r25) | Security risk management | Risk register untuk data siswa, submission, integrations. |
| ISO/IEC 27017:2026 [[R26]](99-referensi.md#r26) | Cloud security | Shared responsibility, cloud control baseline. |
| ISO/IEC 27018:2025 [[R27]](99-referensi.md#r27) | PII in public cloud | Proteksi data pribadi pada layanan cloud. |
| ISO/IEC 27701:2025 [[R28]](99-referensi.md#r28) | Privacy information management | Governance privacy, roles, records, controls. |
| ISO/IEC 27034-1:2011 [[R29]](99-referensi.md#r29) | Application security | Secure application lifecycle untuk LMS/judge/dashboard. |
| ISO/IEC 20000-1:2018 [[R30]](99-referensi.md#r30) | IT service management | Support, incident, request, change, service quality. |
| ISO 22301:2019 [[R31]](99-referensi.md#r31) | Business continuity | Continuity untuk contest/judge/LMS dan backup/restore. |
| ISO/IEC 15408 series:2026 [[R32]](99-referensi.md#r32) | Common Criteria | Relevan bila membutuhkan security assurance formal pada komponen tertentu. |
| ISO/IEC 25010:2023 [[R33]](99-referensi.md#r33) | Software product quality | Quality model untuk usability, reliability, security, performance. |
| ISO/IEC/IEEE 12207:2026 [[R34]](99-referensi.md#r34) | Software life cycle | Governance siklus pengembangan platform. |
| ISO/IEC 40500:2025 [[R35]](99-referensi.md#r35) | WCAG 2.2 | Aksesibilitas platform pembelajaran. |
