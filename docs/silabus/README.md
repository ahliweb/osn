## Ringkasan Eksekutif

Silabus ini merupakan kurikulum pembinaan OSN Informatika yang langsung dapat digunakan oleh mentor, sekolah, lembaga pelatihan, dan platform AhliKoding.com. Struktur pembelajaran dibangun dari fondasi pemrograman C++ dan computational thinking, dilanjutkan analisis kompleksitas, matematika diskrit, complete search, greedy, dynamic programming, graph/tree, struktur data, geometri dasar, dan contest engineering. Latihan dimulai sejak minggu pertama dan meningkat secara bertahap menuju simulasi OSN-K, OSN-P, dan kesiapan tingkat nasional. [[R1]](99-referensi.md#r1)[[R2]](99-referensi.md#r2)[[R3]](99-referensi.md#r3)

Materi inti mengikuti rumpun resmi OSN Informatika 2026: dasar pemrograman; operasi logika/bitwise; aritmetika; aturan berhitung; rekursi; pencarian/pengurutan; strategi pemecahan masalah; struktur data; graph/tree; dan geometri dasar. Silabus ini juga menggunakan IOI sebagai benchmark internasional, tetapi perlu diperbarui setiap kali versi resmi IOI/OSN berubah. [[R1]](99-referensi.md#r1)[[R7]](99-referensi.md#r7)[[R8]](99-referensi.md#r8)

> **Prinsip utama** - Pembinaan tidak berorientasi menghafal algoritma. Setiap topik harus selalu melewati siklus: pahami masalah -> modelkan -> baca constraint -> estimasi kompleksitas -> pilih strategi/struktur data -> implementasi -> test/debug -> upsolve -> refleksi.
