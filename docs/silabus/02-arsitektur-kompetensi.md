# 2. Arsitektur Kompetensi dan Tahapan Kompetisi

## 2.1 Sepuluh rumpun materi resmi

| Rumpun | Cakupan operasional |
| --- | --- |
| Dasar pemrograman | C++ syntax/semantics, variabel, tipe data, ekspresi, I/O, percabangan, perulangan, fungsi/parameter. |
| Logika & bitwise | Boolean, truth table, implikasi/biimplikasi/XOR, modus ponens/tollens, operasi bit. |
| Aritmetika | Integer, paritas, divisibility, modular arithmetic, modular exponentiation, prime, fractions, number theory, sets. |
| Aturan berhitung | Rule of sum/product, barisan, Fibonacci, permutasi/kombinasi, probabilitas, pigeonhole, inclusion-exclusion, Pascal/binomial. |
| Rekursi | Konsep rekursi, fungsi/prosedur rekursif, divide-and-conquer, backtracking. |
| Search & sort | Linear/binary search, bubble/insertion, quick/merge/heap sort. |
| Strategi problem solving | Complete search + pruning, greedy, divide-and-conquer, dynamic programming. |
| Struktur data | Primitive types, array/multidimensi, string, stack/queue, binary heap, DSU, Fenwick/Segment Tree. |
| Graph & tree | Representasi, BFS/DFS, connectivity, shortest path, MST, rooted tree, LCA. |
| Geometri dasar | Titik/koordinat, garis/segmen/sudut, bangun dasar, Euclidean distance, Pythagoras, definisi convex hull. |

Cakupan tersebut mengikuti halaman Silabus OSN Informatika 2026. [[R1]](99-referensi.md#r1)

## 2.2 Karakter tiap tahap kompetisi

| Tahap | Dominan kompetensi | Model latihan |
| --- | --- | --- |
| OSN-K | Computational thinking, modeling, logika, membaca algoritma C++, tracing, kompleksitas; 30-50 soal/2,5 jam. [[R2]](99-referensi.md#r2) | Worksheet analitis, dry-run, Bebras-style, short coding, quiz kompleksitas. |
| OSN-P | 5-8 studi kasus/3 jam; tiap kasus memuat 3 soal pemahaman + 1 soal pemrograman dengan subsoal mudah/sulit. [[R3]](99-referensi.md#r3) | Partial scoring, baseline -> optimized solution, contest 3 jam, postmortem. |
| OSN Nasional | Integrasi materi, implementasi presisi, daya tahan contest, strategi poin. | Mixed-topic contest, arsip nasional, stress testing, editorial review terbatas. |
| TOKI/IOI extension | Breadth/depth sesuai silabus IOI terbaru. | Hanya setelah core lokal stabil dan syllabus check dilakukan. |
